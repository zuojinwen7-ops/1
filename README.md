# 拾级 · CFA 一级学习空间

**在线使用：https://zuojinwen7-ops.github.io/1/**

面向基础薄弱、英语起步阶段的个人中文冲刺网站。已按 **2026 年 11 月 11 日考试、每天 4 小时**设置：10 月 23 日开始，含考试日共 20 天。日期和时长可在网站右上角头像或“学习设置”中修改。

## 打开使用

**最方便的方式：下载 `dist/index.html`，直接用浏览器打开。** 这个文件已包含全部样式、讲义与功能，可离线使用。

网站没有运行依赖、账号、数据库或外部字体。根目录的 `index.html` 也已包含全部配套内容，可单独使用，避免文件预览器找不到样式和脚本。开发源文件分为以下几部分：

```text
index.html       生成的完整入口（样式与脚本均内联）
src/index.template.html 页面与导航的开发模板
styles.css       桌面 / 手机样式
app.js           计划、刷题、复习、计时和本地保存
study-data.js    中文讲义、原创题目、词卡、20 天安排
tests/           浏览器功能验证（使用网站不需要运行）
scripts/build.py 生成单文件离线版本（Python 标准库）
dist/index.html  可直接下载打开的单文件网站
.github/workflows/deploy-pages.yml GitHub Pages 发布工作流
DEPLOY.md        公网发布流程与当前访问要求
```

建议通过固定的本地地址打开，方便浏览器持续保存进度。在仓库目录运行：

```bash
cd /workspace/1
python3 -m http.server 8000 --bind 0.0.0.0
```

在本机运行时，在浏览器地址栏输入 `http://localhost:8000`。云环境中需使用所在平台支持的端口访问功能。网站现已通过 GitHub Pages 上线；后续部署与验证方式见 [DEPLOY.md](DEPLOY.md)。

## 第一天怎么用

1. 进入“今日学习”，点击“开始今日学习”，先做 8 道基础诊断题。
2. 答题后看解析；答错时标记概念、英语、计算或审题问题，写一句错因。
3. 到“知识与公式”理解定量方法的小例子，合上材料复述，再做题。本站提纲只负责搭建入门理解，完整内容要配合报名年份的官方教材和题库。
4. 到“金融英语”学习 8–12 个新词，先回忆再翻面。次日优先复习到期内容。
5. 完成实际学习后手动勾选任务，不以“打满勾”为目标。计时器可帮助分段专注，学习时长不自动等于掌握程度。

## 学习安排的依据与限制

- 前 6 天建立金融数学、财报与核心词的基础；第 7–15 天覆盖主干并混合练习；第 16–17 天分节模拟，第 18 天修复，第 19 天约 90 分钟轻复习，第 20 天参加考试。
- 采用闭卷回忆、间隔 1 / 3 / 7 天复习、交错练习、错因归类和睡眠保护。该间隔是易执行的默认方案，并非对个人保证最优。
- 科目参考权重按近年公开结构列出；当前云环境无法在线核验 CFA 官网，均标为未核验。请在“学习方法与资料来源”中通过官方入口核对自己考季的考纲、考试要求及 PSM 截止日。
- 本站含 10 科入门讲义、66 个词条、32 道原创三选一基础题和 8 组英文拆句。它们不等于完整考纲、正式题库或模拟卷，正确率不能预测通过率。
- 模拟须使用官方 Learning Ecosystem 或其他合法取得的完整模拟卷。每节 90 题、135 分钟；两节至少 270 分钟，不含休息和复盘。分两天练习不能验证连续完整考试的耐力。
- 每天 2 小时会减少新课与练习范围；模拟日仍需额外预留时间，正式计时不会缩短。6 小时安排增加练习与复盘，模拟作答仍固定 135 分钟。网站不承诺 20 天能够从零掌握全部考纲或保证通过。
- PSM 属于独立要求，先在候选人账户核对完成状态和个人截止日；不要把通过选择题考试误认为满足全部成绩领取要求。

## 保存与备份

记录保存在浏览器 `localStorage` 的 `shiji-cfa-v1` 项目中，不会上传。刷新仍保留答题、笔记、日期设置、打卡和复习安排；当前未完成的答题轮次与专注计时不跨刷新保留。

不同设备、不同浏览器、不同网址和不同端口的记录不自动共享。清理浏览器数据可能删除进度。请每隔两三天从“学习设置”导出 JSON 备份；导入前会要求确认替换。笔记会按纯文本显示。

## 验证

修改模板、样式或脚本后，重新生成根目录入口与离线单文件：

```bash
python3 scripts/build.py
```

语法检查：

```bash
node --check app.js
node --check study-data.js
```

当前开发环境已有 Python Playwright 和 Chromium。运行浏览器集成测试：

```bash
python3 tests/test_site.py
python3 tests/test_preview.py
```

测试使用独立的本地端口、临时浏览器上下文和固定时间，不读取真实学习记录。覆盖导航、打卡与笔记持久化、日期和时间设置、答题及错题修复、间隔复习、导入导出、文本转义、计时和手机布局。其他机器上运行测试需先安装 Playwright，并提供 `/usr/bin/chromium`；使用网站本身不需要这些工具。
